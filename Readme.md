## ⚙️ Hướng Dẫn Môi Trường & Chạy Code

Repository này được cấu trúc theo dạng **Eclipse Workspace**.

**Yêu cầu hệ thống:**

1.  **Java Development Kit (JDK):** Khuyến nghị cài đặt JDK 8 hoặc mới hơn.
2.  **IDE:** [Eclipse IDE for Java Developers](https://www.eclipse.org/downloads/).

**Cách mở project:**

1. Clone repository về máy.
2. Mở **Eclipse**.
3. Tại cửa sổ **Eclipse Workspace Launcher**, chọn đường dẫn (Browse) trỏ thẳng vào thư mục `66133552-JavaProgaming` này.
4. Eclipse sẽ tự động nhận diện tất cả các project con (nhờ có thư mục `.metadata`).
5. Chuột phải vào file `.java` chứa hàm `main` ở bài bạn muốn kiểm tra $\rightarrow$ Chọn **Run As** $\rightarrow$ **Java Application**.
